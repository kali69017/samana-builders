What is a Project Cost? These are construction / development costs spent to build a project — materials, labor, contractors, transportation and other direct build costs. Each is linked to a project and can be set to draft → approved → paid.
Only "paid" costs count toward the project budget and the Project Investment & Finance view.
Different from Expenses (general company/project overhead like marketing or admin) and Office Expenses (office rent, utilities, stationery).
