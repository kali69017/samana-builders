Project Investment & Finance

ℹ️
How to use this page This is a per-project overview combining four numbers:
  • Investment — total capital the company has put into the project (set it via the Investment button). Manually maintained.
  • Budget — planned spend by category (set it via the Budget button).
  • Costs — actual construction costs recorded under Finance → Project Costs (materials, labor, contractors, transport). Only paid costs count here.
  • Revenue — money received from bookings on this project (advance payments).
Profit / Loss = Revenue − Costs. Remaining = Budget − Paid costs. Use the buttons to set each project's budget and investment — the totals update automatically from recorded bookings and costs.
